# Machine-Learning-Assignment-1---Data-Preprocessing
# House Prices: Advanced Regression Techniques - Data Preprocessing

This repository contains Assignment 1 for the Machine Learning course. The goal of this project is to apply full data preprocessing steps, including data retrieval, cleaning, exploratory data analysis (EDA), and feature engineering on the House Prices dataset.

## Project Structure
- `ML_Ass1.ipynb`: The main Google Colab Notebook containing the code and data science workflow.

## How to Run on Google Colab
1. Download the `ML_Ass1.ipynb` file from this repository.
2. Go to [Google Colab](https://colab.research.google.com/) and upload the notebook.
3. Upload the dataset files (`train.csv` and `test.csv`) directly to your Colab session storage.
4. Run the cells in `ML_Ass1.ipynb` sequentially.
